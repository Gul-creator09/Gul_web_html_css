## 🌟 About This Portfolio

This is my **personal portfolio website** showcasing my journey as a **B.S. Artificial Intelligence** student. It highlights my **skills**, **experience**, **certifications**, and **projects** in a modern, responsive, and interactive design.

### ✨ Features

- 🎨 **Modern Dark Theme** — Sleek and professional design
- 📱 **Fully Responsive** — Works on all devices (mobile, tablet, desktop)
- 🍔 **Mobile Navigation** — Hamburger menu with smooth toggle
- 🎠 **Experience Slider** — Auto-sliding with 5 experiences
- 🎠 **Certification Slider** — Auto-sliding with 4 certifications
- 🚀 **Projects Grid** — 9 projects with icons and descriptions
- ⌨️ **Typing Animation** — Dynamic role display
- 🌐 **Social Links** — LinkedIn, GitHub, Twitter
- 📬 **Contact Section** — Email and phone information
